# 모둠 발표 성장 점수판

수업 시간 모둠별 발표 점수를 기록하는 웹앱입니다. 정적 HTML/CSS/JS 한 파일로 동작하며 GitHub Pages로 배포되어 있습니다.

## 기능

- 모둠 1~6 점수판, 발표 점수가 쌓일수록 알 🥚 → 새끼 용 🐲 → 드래곤 🐉 으로 진화
- 진화 단계 전환 시 레벨업 애니메이션과 색종이 효과
- 발표할 모둠을 무작위로 뽑는 돌림판 (발표 완료한 모둠은 판에서 제외 가능)
- 진화 기준 점수, 발표당 점수 등을 조정할 수 있는 설정
- 점수와 설정은 브라우저 localStorage에 자동 저장

## 로컬 실행

`index.html` 파일을 브라우저로 열면 바로 사용할 수 있습니다.
